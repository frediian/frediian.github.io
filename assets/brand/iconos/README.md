# Iconografía Frediian

SVG editables 24 × 24 px, trazo `1.8`, extremos redondeados, azul `#17699A`.

Usos: desarrollo, consultoría, datos, infraestructura, seguridad, automatización, monitoreo, e-commerce, dirección y contacto.

Tamaños recomendados: 20 px (controles), 24 px (tarjetas), 28-32 px (secciones). Mantener el estilo monoline; no añadir sombras, destellos o trazos de circuito decorativos. Para personalizar color, sustituir `stroke` por `currentColor` o el color de marca permitido.
